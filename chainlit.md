# Agent IA Data Analyst - Hybride

Posez une question en langage naturel sur les données de l'entreprise :

- **Northwind** (ERP/CRM : clients, commandes, produits, employés, fournisseurs)
- **Online Retail II** (export e-commerce réel, en GBP)

L'agent choisit lui-même les outils nécessaires pour répondre : requête SQL,
calcul Python, graphique, export de fichiers, rapport narratif traçable, ou
synthèse d'avis clients. Il peut enchaîner plusieurs outils pour une même
question (ex : "trace un graphique" après une question sur les ventes).

Donnez votre avis avec les boutons 👍 / 👎 sous chaque réponse - il alimente
la base de feedback utilisée pour évaluer et améliorer l'agent.
